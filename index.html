Code Preview について
GitHub リポジトリ・ZIP・ローカルフォルダを読み込み、複数ファイルのコードを編集しながら動作を確認できる実験用ツールです。HTML／CSS／JavaScript はブラウザでプレビューできます。Next.js などのフレームワークや PHP・Python・C 系言語などは、実行環境・ビルド環境が必要な場合があります。読み込んだファイルはこの画面内で編集され、元のリポジトリへ自動保存はされません。
