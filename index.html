Code Preview について
GitHub リポジトリ・ZIP・ローカルフォルダを読み込み、複数ファイルのコードを編集しながら動作を確認できる実験用ツールです。
  • HTML／CSS／JavaScript：ブラウザ内でプレビューできます。
  • JSX／TSX：単一ファイルの簡易プレビューに対応します。
  • Next.js・Vite など：隔離されたリモート環境で依存関係をインストールし、開発サーバーを起動します。
  • PHP・Python・Go・Rust・C/C++・Ruby：隔離されたリモート環境でコードを実行し、標準出力とエラーを確認できます。
  • 編集内容はこの画面内だけに反映され、GitHub へ自動保存されません。
